# Student Portfolio

A modern, interactive, student portfolio website designed to showcase web development projects, technical skills, and academic achievements.

[View Live Demo](https://pharaos-hub.github.io/Student-Portfolio)

## Features

- Responsive Design: Fully optimized for mobile, tablet, and desktop screens.
- Interactive UI: Includes smooth navigation transitions, project filtering, and theme switching.
- Project Showcase: Highlights key projects with direct links to source code and live demos.
- Contact Section: Functional contact form setup for direct inquiries.
## Tech Stack

- HTML5 and CSS3
- GitHub Pages (Deployment & Hosting)
